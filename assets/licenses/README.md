# Licence texts

Exact copies of the licence texts that ship with the application and are shown in its About dialog.

- `iced-MIT.txt`: licence of the iced crate family, copied from the iced 0.14.0 source.
- `ibm-plex-sans-OFL.txt`, `ibm-plex-mono-OFL.txt`, `ibm-plex-sans-kr-OFL.txt`: SIL Open Font License 1.1 with the IBM copyright lines of the embedded and downloadable IBM Plex faces, copied from the `@fontsource` packages.

The Noto Sans script packs (Arabic, Devanagari, Bengali, Telugu) and the Chinese packs are also distributed under the SIL Open Font License 1.1. Their licence files are added next to these when the font-pack subcommand generates the packs, because each carries its own copyright line.
