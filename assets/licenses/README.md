# Licence texts

Exact copies of the licence texts that ship with the application and are shown in its About dialog.

- `iced-MIT.txt`: licence of the iced crate family, copied from the iced 0.14.0 source.
- `ibm-plex-OFL.txt`: SIL Open Font License 1.1 with the IBM copyright notice and the reserved font name "Plex", copied from the IBM Plex repository. It covers IBM Plex Sans, Mono, Sans KR, Sans JP, Sans SC and Sans TC.
- `noto-OFL.txt`: the same licence with the copyright notice of the Noto project, copied from its Latin, Greek and Cyrillic repository. The Arabic, Devanagari, Bengali and Telugu fonts carry the same notice with their own repository name.

The licence reserves the name "Plex" for unmodified fonts. The embedded IBM Plex Sans and Mono faces are therefore shipped unmodified, and every subset the font-pack tool writes (the Korean, Japanese and Chinese packs and the Latin fallback face) carries a different family name. See `assets/fonts/README.md`.
